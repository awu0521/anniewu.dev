About this demo

What was the bug?

The robot’s rule ignored everything about the game and always returned seat 1. The fix looks at how many turns each player has had and picks whoever is furthest behind, so everyone gets an even share.

Honest label: a scripted simulation, not a live language model and not HATRIC’s real code. In HATRIC these decisions come from an LLM agent working with vision input.
